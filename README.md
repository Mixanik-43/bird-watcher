# bird-watcher

Практические задания по PyTorch и дообучению VLM на подвыборке CUB-200-2011.

Репозиторий наполняется: ResNet-18, собственный LoRA-модуль, Qwen3.5-0.8B и вопросы об атрибутах фотографий.

Изображения не публикуются в GitHub; используется загрузчик исходного CUB для образовательного применения.
