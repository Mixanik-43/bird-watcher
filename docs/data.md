# Формат данных и свои снимки

В наборе три папки `train/<вид>`, `val/<вид>`, `test/<вид>`, обычные JPEG,
`classes.json` и `manifest.jsonl`. Нет Hugging Face Dataset, Parquet или базы данных.
Имена файлов могут быть любыми. Загрузчик читает manifest, поэтому одного копирования
JPEG в папку недостаточно: добавьте строку с относительным путём.

`classes.json` — упорядоченный список названий. Индекс в списке — `label`:

```json
["Gadwall", "European_Goldfinch", "Mallard", "Common_Raven", "House_Sparrow", "Bank_Swallow", "Barn_Swallow", "Bohemian_Waxwing"]
```

Одна строка manifest для своего снимка выглядит так:

```json
{"image_id":"camera-2027-001","image":"train/house_sparrow/001.jpg","label":4,"species":"house_sparrow","split":"train","attributes":{}}
```

Это уже подходит для ResNet. `image_id` должен быть уникальным. Поле `sha256` в CUB
служит проверке точных дублей; загрузчик не требует его у собственных снимков.
Для нового вида добавьте название **в конец** classes.json и используйте новый индекс.
Не меняйте номера старых классов. При изменении числа классов переобучите голову;
checkpoint со старым числом выходов напрямую не загрузится в новую модель.

Для VLM заполните только проверенные атрибуты конкретной фотографии, например:

```json
{"has_bill_shape::cone":"yes","has_breast_color::white":"no"}
```

Все поддерживаемые ключи и формулировки находятся в `birdlab/data.py:QUESTIONS`.
Если крыло не видно или вы не уверены в ответе, не добавляйте этот атрибут.
Вопросы автоматически получат split своего изображения. Для дополнительных задач
нужно расширить словарь QUESTIONS и разметить соответствующие ответы.

Сначала сделайте копию подготовленного набора. Разделяйте свои фотографии по визитам
птиц/сериям фотоловушки: соседние кадры не должны попасть одновременно в train и test.
Для проверки переноса на фотоловушку сохраните отдельный test из собственных снимков.
Оценка на CUB не заменяет такую проверку.

```bash
python scripts/train_resnet.py --data data/my_birds
python scripts/train_vlm.py --data data/my_birds --steps 50
python scripts/predict.py --help
```

В ноутбуках установите `BIRD_DATA` на абсолютный путь к набору до первой ячейки.
